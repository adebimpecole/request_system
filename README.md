every department head is an approver. the request first gets to them
only a requester can close their request
approvers can make requests too
a requester cannot approve their request
requests have comments where disvussions or statements can be made. requesters can also plead their case if the request is denied 
we have approval levels. the first level is the department head and then the panel of approvers(verifying and funding approvers)
requests can be sent to the previous level approver or requester to ask a question about the request. during this time the approver must not approve or decline the request unless ready to pass it to the next approver.
